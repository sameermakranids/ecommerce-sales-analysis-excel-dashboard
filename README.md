# E-Commerce Sales Analysis Dashboard

## 📊 Project Overview

This project is an interactive E-Commerce Sales Analysis Dashboard created using Microsoft Excel.

The dashboard provides a clear view of sales performance, profitability, order volume and product performance through interactive visualizations and filters.

## 🎯 Project Objective

The objective of this project is to analyze e-commerce sales data and identify important business trends and performance indicators.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data Analysis
- Data Visualization
- Dashboard Design

## 📌 Key KPIs

- Total Sales
- Total Profit
- Quantity Sold
- Number of Orders
- Profit Margin
- Year-over-Year (YoY) Growth

## 📈 Dashboard Analysis

The dashboard includes:

- Sales and Profit Analysis
- Category-wise Profit
- Category-wise Sales Share
- Sales by State
- Top 5 Sub-Categories by Sales
- Region-wise Analysis
- Segment-wise Analysis
- Year-wise Analysis

## 🎛️ Interactive Filters

Users can filter the dashboard using:

- Region
- Segment
- Year
